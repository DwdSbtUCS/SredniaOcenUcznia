# Średnia ocen ucznia — Python oraz C#

Prosty program konsolowy obliczający średnią z podanej liczby ocen (w skali 1–6) i sprawdzający, czy uczeń zdał (średnia co najmniej `3.0`).

## Struktura repozytorium

```text
.
├── python/
│   └── srednia_ocen.py
├── csharp/
│   ├── srednia.cs
│   └── SredniaOcen.csproj
└── README.md
```

## Uruchomienie

### Python
```bash
python python/srednia_ocen.py
```

### C#
```bash
dotnet run --project csharp/SredniaOcen.csproj
```
(albo `dotnet run` wewnątrz folderu `csharp`)
